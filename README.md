# Text to Video Generator

Creates short videos for TikTok, Instagram Reels, and YouTube Shorts from text, using a REST API and the Model Context Protocol (MCP).



## Tools & Technologies Used

- [Remotion](https://remotion.dev/) for programmatic video generation
- [Whisper](https://github.com/ggml-org/whisper.cpp) for speech-to-text
- [Pexels](https://www.pexels.com/) for video content
- [FFmpeg](https://ffmpeg.org/) for audio/video processing
- [Kokoro](https://github.com/hexgrad/kokoro) for TTS
